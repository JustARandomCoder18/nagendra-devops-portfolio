# Local Development

## Requirements

- Node.js 22+
- npm
- Git

## Setup

```bash
git clone <repository-url>
cd nagendra-devops-portfolio
npm install
npm run dev
```

## Production build check

```bash
npm run build
```

## Content updates

Portfolio content is data-driven in `src/data/`. Update profile, skills, projects, and experience there rather than duplicating content across UI components.
